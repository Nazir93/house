### Что CSV подтверждает / меняет в приоритетах

1. **Главная = почти всё.** Этап 1 без главной бессмысленен.
2. **Проблема №1 — CTR, не отсутствие позиций.** «услуги по строительству домов»: ~201 показ около 10-й позиции, **0 кликов** — ровно кейс плохого сниппета (в т.ч. CODE1618 раньше).
3. **Клики почти только с бренда.** Коммерческие запросы не кликают → правим сниппет и первый экран, а не плодим URL.
4. **Газобетон в запросах есть (~30 показов), но клеится к `/`, не к `/projects/gazobeton`.** Этап 2 (усилить материаловые страницы + перелинковка с главной) нужен, чтобы снять нагрузку с главной. Новые `/stroitelstvo-domov-iz-*` CSV не оправдывает на этапе 1.
5. **`tehnadzorspb.ru` в CSV реален** (35 показов на проектировании). В коде сайта строки нет — это артефакт выдачи/соседства. Meta/H1 проектирования всё равно усиливаем.
6. **Кластер «отделка»** тянет показы на главную с чужими доменами в запросе. Не оптимизировать главную под отделку; отделка — `/services/otdelka`, не размывать хаб.
7. **Регион СПб/ЛО доминирует** по полезным запросам; чужие регионы и длинные AI-запросы — шум, GEO-города не делать.
8. При разборе абзаца ТЗ: если CSV противоречит «создать новый URL» — **сначала CTR живого URL**, новый URL только на этапе 2 с явным решением.

## Как разбирать абзац заказчика

1. Найти пункт в таблице ниже.
2. Сверить с блоком **Факты из Вебмастера**: есть ли показы/клики/URL в CSV.
3. Действие только одно: **сделать / адаптировать / пропустить / уже есть**.
4. Копирайт правим в `frontend/src/lib/seo/*.ts` и связанных `*.test.ts`, не размазываем по JSX.
5. `/lp/*` не трогаем как органику: это реклама, `noindex` + `Disallow: /lp/`.
6. Новые URL не создаём, пока в плане явно не открыт этап 2.
7. GEO-страницы городов не делаем. Регион — overlay из geo-плана, не `/vsevolozhsk`.
8. После фичи: `npm run test` и `npm run check` в `frontend/`.
9. Деплой — только по отдельной команде.

## Этапы

### Этап 1 — сейчас (CTR и гигиена)

Приоритет по CSV: **главная → проекты → проектирование**. Делаем по абзацам, без новых разделов.

1. Главная: Title, Description, один HTML H1, короткий текст под H1, CTA — цель снять 0 CTR у «услуги по строительству домов».
2. Сниппет: кредит студии уже вне выдачи. Не откатывать. После правок meta — переобход в Вебмастере.
3. Главная: текстовые ссылки с блока материалов на `/projects/{материал}` (чтобы газобетон/кирпич уходили с `/` на свои URL).
4. Главная: блок построенных домов — данные из портфолио, не новые карточки.
5. `/projects`: Title, Description, H1 под «авторские проекты домов», intro, SEO-блок **после** каталога.
6. `/services/proektirovanie`: Title, Description, H1. tehnadzorspb в коде — нет; в CSV шум зафиксирован.
7. Canonical / sitemap / robots: проверить, не ломать. LP не в sitemap.
8. Зеркало `частьдуши.рф` → 301 на тот же путь `chastdushi.ru` (проверка, не выдумывать редиректы).

Не в этапе 1: новые посадочные `/stroitelstvo-domov-iz-*`, GEO, оптимизация главной под «отделку», WhatsApp, смена URL.

### Этап 2 — коммерция материала

Только после этапа 1 и явной команды.

Усилить `/projects/{материал}` до коммерческой посадочной: цена, что входит, технология стены, проекты, объекты, этапы, FAQ, CTA.  
Перелинковка: главная ↔ материал ↔ проект ↔ объект ↔ калькулятор ↔ проектирование.

Новые `/stroitelstvo-domov-iz-*` — только если заказчик письменно подтвердит и мы закроем каннибализацию.

### Этап 3 — не сейчас

Категории проектов уже есть: `/projects/odnoetazhnye`, `dvuhetazhnye`, `do-150-m2`, `150-220-m2`. Не плодить вторые.  
GEO-города — отдельный контур после geo-rbac, не автогенерация.
