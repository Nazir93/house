**Что сделать в Вебмастере:**
1. Инструменты → **Проверка мобильных страниц** → проверить `/` и 2–3 URL из списка примеров рекомендации.
2. Если зелёные — снова **«Я всё исправил»**.

Если Вебмастер покажет конкретные URL с горизонтальным скроллом — пришлите список, добьём точечно.
